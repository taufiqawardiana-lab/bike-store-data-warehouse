# Bike Store Data Warehouse

## Project Overview
This project focuses on designing and developing a data warehouse solution for Bike Store sales, inventory, and profitability analytics using PostgreSQL and SQL.

The objective of this project is to integrate sales and inventory datasets from multiple store branches into a centralized analytical database to support operational and business decision-making.

---

## Business Problems
- Difficulty monitoring inventory across multiple stores
- Inconsistent sales reporting between branches
- Overstock and stockout risks
- Limited visibility into product profitability trends

---

## Project Objectives
- Build a centralized analytical database
- Analyze product sales trends
- Monitor inventory movement
- Evaluate store and staff performance
- Support profitability analysis

---

## Tech Stack
- PostgreSQL
- SQL
- Data Modeling

---

## Dataset
The dataset contains:
- Products
